Privacy Policy

Last updated: August 18, 2025 | App: Easy FB Poster (content-pulse)

1. Information We Collect

We collect only the data necessary for the app to function:

  • Facebook Page Access Token — provided by you to post videos to your page
  • Video files & captions — temporarily stored on our server during upload, deleted after posting
  • Account email — for authentication via Supabase Auth

2. How We Use Your Data

  • Post videos to your Facebook page via Graph API
  • Schedule and manage your posting queue
  • Authenticate you securely (Supabase Auth)

We do NOT sell, share, or use your data for advertising.

3. Data Storage & Security

  • Tokens & queue data stored in Supabase (PostgreSQL) with Row Level Security
  • Video files stored temporarily on server disk, deleted immediately after successful post
  • All communication over HTTPS

4. Third-Party Services

  • Facebook (Meta) — Graph API for posting
  • Supabase — database & authentication
  • Koyeb — cloud hosting (if deployed there)

5. Your Rights

You can:

  • Revoke Facebook token anytime in the app
  • Delete your account & all data via the app UI
  • Request data deletion by emailing us

6. Data Deletion

To request deletion of your data, email innerlightroom@gmail.com or use the in-app delete function.

7. Contact

Questions? Email: innerlightroom@gmail.com
